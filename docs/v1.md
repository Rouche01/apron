# Gateway `/v1` public contract

This is the **agent-facing** HTTP API for Computer Runtime. Bind any model/host via [BINDING.md](../BINDING.md); do **not** put LLM calls in the gateway or workers.

Live OpenAPI while running: `http://localhost:9000/docs` · `http://localhost:9000/openapi.json`  
Gateway package version (OpenAPI `info.version`): **0.3.0**

## Compatibility freeze

| Guaranteed for `/v1` | May change without a `/v1` bump |
|----------------------|----------------------------------|
| Paths and methods below | Ops-only seat/device admin details |
| Auth header shape | Burst / k3s internals |
| Lease / park / recycle semantics | Worker image internals |
| Core JSON fields on lease + screenshot/action | Extra fields on responses (additive OK) |
| Status codes called out below | New optional query/body fields (additive OK) |

**Breaking changes** to guaranteed behavior require a new major API prefix (e.g. `/v2`) or a clearly versioned deprecation notice in this file and the release notes.

**Hard rule:** the gateway never calls an LLM. Inference stays in the agent host.

## Auth

```http
Authorization: Bearer <COMPUTER_API_TOKEN>
```

| Condition | Result |
|-----------|--------|
| Token configured and header missing/wrong | **401** `invalid or missing bearer token` |
| Token **unset** (empty) | Auth skipped — **dev only**; do not expose publicly |
| `TENANTS_PATH` set | Bearer must match a tenant API key or ops `COMPUTER_API_TOKEN` — [docs/hosted.md](hosted.md) |

## Seat lifecycle (agents)

```text
free → leased → parked → free   (reserved seats)
                ↘ recycle / idle → free (or destroy if ephemeral burst)
```

| Term | Meaning |
|------|---------|
| **Lease** | Exclusive claim: `POST /v1/sessions` |
| **Park** | Soft `DELETE` — drop claim, keep seat warm for same `session_id` / `job_id` |
| **Acquire** | Re-lease a parked seat by `session_id` |
| **Recycle** | Wipe worker state and free (or destroy burst seat); stops cloud-phone billing |

Lease TTL expiry **parks** (does not wipe). Parked idle TTL then recycles/frees.

## Agent routes

Base URL: `{GATEWAY_PUBLIC_BASE}` (e.g. `http://localhost:9000`).

### Sessions

| Method | Path | Success | Notes |
|--------|------|---------|--------|
| `POST` | `/v1/sessions` | **200** `LeaseResponse` | Body: optional `agent_id`, `job_id`, `ttl_sec` (30–86400), `kind` (`desktop`\|`phone`, default `desktop`), `seat_id` (exact pin), `record` (bool; journal opt-in) |
| `POST` | `/v1/sessions/{id}/heartbeat` | **200** | Extend lease TTL |
| `POST` | `/v1/sessions/{id}/acquire` | **200** | Parked → leased |
| `DELETE` | `/v1/sessions/{id}` | **200** | Soft park; `?recycle=true` → wipe + free |
| `POST` | `/v1/sessions/{id}/recycle` | **200** | Wipe + free |
| `POST` | `/v1/sessions/{id}/reset` | worker status | Forward reset to worker |

**`POST /v1/sessions` selection (phone):**

- `job_id` match on a **parked** seat of the same `kind` → reattach  
- `seat_id` set → exact pin (physical or cloud)  
- `kind=phone` without `seat_id` → **cloud seats only** (never a random physical)  
- No free claimable seat (and burst off/full) → **503**

**LeaseResponse** (stable fields): `session_id`, `api_base`, `vnc_url`, `expires_at`, `kind`, `seat_id`, `agent_id`, `job_id`, `recording`.

### Observe / act

| Method | Path | Notes |
|--------|------|--------|
| `GET` | `/v1/sessions/{id}/screenshot` | `{ "image": "<base64 png>" }` (shape may include other keys) |
| `GET` | `/v1/sessions/{id}/observe` | Phone: screenshot + trimmed UI tree; **desktop → 404** |
| `POST` | `/v1/sessions/{id}/action` | Body `type` + coords/text/… — see BINDING.md / OpenAPI |

Observe/act require an **exclusively leased** session (not merely parked). When `recording` is true, successful screenshot/observe/action events are appended to a journal (frames on disk; not continuous video).

### Recordings (past sessions)

Opt-in journals outlive park/recycle. TTL is `RECORDING_TTL_SEC` (default 7 days) — **distinct from** `PARKED_TTL_SEC`. Soft release / recycle finalize the journal (`ended_at`); they do not delete it.

| Method | Path | Notes |
|--------|------|--------|
| `GET` | `/v1/recordings` | List summaries; query `job_id`, `kind`, `limit` |
| `GET` | `/v1/recordings/{id}` | Manifest: meta + events (relative `frame` paths) |
| `GET` | `/v1/recordings/{id}/frames/{name}` | Raw PNG |

## Status codes agents should handle

| Code | When |
|------|------|
| **200** | Success |
| **401** | Bad/missing bearer (when token configured) |
| **404** | Unknown/expired session, or missing seat |
| **409** | e.g. acquire while already leased; seat busy on some ops paths |
| **400** | Validation / kind mismatch / bad pin (`detail` or structured `code` when present) |
| **429** | Hosted plan overage (e.g. `tenant_lease_cap` — concurrent lease cap); see [hosted.md](hosted.md) |
| **503** | No capacity (pool full, burst failed/capped, worker factory error); retry or wait |

Pin failures on lease may surface as **404** / **400** / **409** with codes such as `seat_not_found`, `seat_kind_mismatch`, `seat_busy` (see OpenAPI / error body).

## Ops routes (not required for a minimal agent loop)

Still under `/v1` and the same Bearer auth:

- `GET /v1/seats` — inventory snapshot  
- `GET /v1/seats/{id}/devices` · `/device` — phone ADB  
- `POST /v1/devices/register` · `/unregister` — physical prep  
- `POST /v1/seats/{id}/bind` · `/unbind` — physical runtime bind  
- `GET /v1/recordings` · `/v1/recordings/{id}` · frames — past-session journals (see above)  

`GET /health` and `GET /ready` are unauthenticated ops probes (`/ready` may return **503** when workers are unhealthy). Hosted alert wiring: [hosted-ops.md](hosted-ops.md).

## Out of contract

- Worker `:8000` control APIs (internal only)  
- Direct noVNC / scrcpy control (Watch is view-oriented; drive via `/action`)  
- Any gateway-hosted model, vision loop, or CAPTCHA solver
